# SillyDroid 屏幕常亮

一个独立的 SillyTavern 前端扩展。启用后阻止酒馆页面在前台运行时自动熄屏，效果类似正在播放视频；并支持为「小说自动生成器」守住长任务。

## 安装

在 SillyTavern 的扩展管理页选择从 URL 安装，并填入：

```text
https://github.com/cjhkcjgk3-sys/sillydroid-screen-awake.git
```

安装后刷新页面，在扩展设置里打开“保持屏幕常亮”。也可以把整个仓库目录复制到：

```text
public/scripts/extensions/third-party/sillydroid-screen-awake/
```

## 两档保活策略

1. **系统屏幕唤醒锁（优先）**：`navigator.wakeLock.request('screen')`。正规接口，几乎零耗电。
2. **静音视频保活（兜底）**：唤醒锁不可用时，扩展在页面角落放一个 2×2 像素、无声音、循环播放的极小视频。浏览器会把“正在播放带视频轨的媒体”视为播放视频，从而推迟熄屏——这正是 NoSleep.js 等库多年使用的方式。**纯音频不行**，系统只在乎有没有视频轨。

面板底部会显示环境自检：`安全上下文 / 唤醒锁 / 视频保活 / 任务` 四项状态，以及当前生效的是哪一档。

> 唤醒锁只在安全上下文可用：`http://localhost` / `127.0.0.1` 或 HTTPS。用手机通过 `http://局域网IP:8000` 访问酒馆时会退回视频保活。

## 功耗

常亮状态下电耗主要来自屏幕和页面渲染，不是保活机制本身。扩展提供一个**页面压暗**滑块（0–80%）：在页面上叠一层可穿透点击的黑色遮罩，只降低发光，不改变布局。OLED 屏幕上这是实打实的省电，代价是文字对比度下降。

酒馆侧还有三个立竿见影的设置（UI 设置里）：

- **UI 模糊**（`blur_strength`）调到 `0`：`backdrop-filter` 是最贵的持续 GPU 合成；
- 勾选 **Reduced Motion**：关掉动画与过渡；
- 背景换成**静态纯黑图**：OLED 纯黑像素不发光。

## 无操作自动放开（宽容休眠）

- 面板里可设置“无操作 N 分钟自动放开”（默认 10 分钟，`0` = 永不放开）。到点后释放唤醒锁并暂停视频，屏幕按系统设置正常熄屏；任意触摸、按键、滚动会立刻重新保活。
- 目的是避免“看着看着睡着，整夜亮屏”。

## 与「小说自动生成器」联动

[Novel-Auto-Generator](https://github.com/cjhkcjgk3-sys/Novel-Auto-Generator) 在长任务里会连续跑多轮生成，中途任何一次熄屏都可能让网络请求断掉、任务失败。扩展通过它自己的状态徽章做只读联动，**不需要修改那个插件**：

- 信号：`#nag-status` 的 class 为 `running` 时视为任务运行中（该徽章由插件在每次状态变化时刷新），`paused` / `stopped` 视为不在跑。
- 任务运行期间：忽略“无操作自动放开”的计时，一直保持常亮；
- 任务结束、中断或失败（徽章离开 `running`）：**立即释放唤醒锁**（若最近一分钟内有过操作，则改为重新开始空闲计时，避免突然黑屏）；
- 酒馆自身的生成（`generation_started` / `generation_ended`）同样算作“有活要干”，所以把自定义时长设得很短也不会打断一条长回复；
- 面板里的“与小说自动生成器联动”开关可关闭此行为。

另外提供显式接口，任何插件都能按住屏幕常亮：

```js
globalThis.SillyDroidScreenAwake?.hold('my-task');   // 任务开始
globalThis.SillyDroidScreenAwake?.release('my-task'); // 任务结束/失败
```

若小说插件将来改动了徽章结构，用这套接口即可继续联动（面板自检里的“任务 运行中/空闲/未检测到”可用来确认信号是否还在）。

## 说明

- 默认关闭，开关、压暗、空闲时长、联动开关都保存在 SillyTavern 扩展设置里。
- 不创建音频、不改变酒馆的生成、消息和网络请求逻辑。
- 视频保活片段是运行时用 `canvas.captureStream()` + `MediaRecorder` 现场录制的 16×16 无声 WebM，仓库不附带二进制素材。
- 页面进入后台（切标签、按电源键锁屏）时保活会释放，这是系统要求；返回前台自动恢复。
- 常亮会增加耗电；它不能阻止 Android 其他省电策略中断网络。
